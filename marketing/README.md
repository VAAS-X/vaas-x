# VAAS-X Marketing Console

Internal GTM tool for pitching the **live** product surfaces:

- **SDK / site:** [vaasx.com](https://vaasx.com) (`pip install vaas-x`)
- **MCP:** [vaasxmcp](https://mcp.vaasx.com/mcp) — registry `io.github.VAAS-X/vaasxmcp`

## What it includes

1. **Positioning kit** — one-liners, registry blurbs, LinkedIn, short email, objection handlers, proof stack  
2. **vaasxmcp walkthrough** — simulated `recall` → `remember` → `record_outcome` demo for sales calls  
3. **Agency outreach builder** — outbound / CX / AI / RevOps wholesale emails  
4. **SKU quote slip** — credits, 48h pilot, MCP team, enterprise conversation  

Copy and proof points are locked to public claims from vaasx.com and this repo (14ms / 1.18M episodes, CMAPSS, MCP tool names).

## Run locally

```bash
cd marketing
python3 -m http.server 8080
```

Open `http://localhost:8080`.
